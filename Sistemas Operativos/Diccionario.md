# Diccionario - Sistemas Operativos

## Tema 01 - Virtualización

### Oracle VM VirtualBox Extension Pack

**Qué es:** Paquete adicional de VirtualBox que amplía sus funciones, por ejemplo, con soporte para dispositivos USB 2.0 y 3.0 en las máquinas virtuales. Se instala aparte del programa principal.

### Firmware UEFI

**Qué es:** Firmware moderno que inicializa el hardware y prepara el arranque del sistema operativo; es el sucesor del BIOS tradicional. En una máquina virtual, puede seleccionarse para que el sistema invitado arranque con este tipo de firmware.

### TPM 2.0 virtual

**Qué es:** Módulo TPM 2.0 virtual proporcionado por el hipervisor. Permite a la máquina virtual almacenar claves de forma segura y usar funciones de protección, como el cifrado del disco. El TPM virtual se presenta al sistema invitado como un componente de seguridad propio.
